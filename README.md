# Kaamil Khan Portfolio

Software engineering portfolio for Kaamil Khan, built with Next.js and Tailwind CSS.

The site is designed for backend, systems, and full-stack recruiting, with project case studies, resume access, and direct contact links.

## Stack

- Next.js
- React
- Tailwind CSS
- TypeScript

## Project Structure

- `src/data/portfolio.ts` contains the main site content
- `src/components/` contains the shared UI components
- `src/app/` contains the page routes and app layout
- `public/resume/kaamil-khan-resume.pdf` is the live resume file
